# Happy Tours - Dubai Travel Packages

A modern travel booking website built with Next.js and TypeScript, showcasing tour packages and activities in Dubai.

## Features

- Responsive design works on mobile, tablet, and desktop
- Interactive tour cards with carousel image galleries
- Activity tickets with booking functionality
- Clean UI with modern design patterns
- Seamless tab navigation between Tours and Activities

## Tech Stack

- Next.js
- TypeScript
- SCSS Modules
- React Icons

## Getting Started

First, clone the repository:

```bash
git clone https://github.com/yourusername/happy-tours.git
cd happy-tours
```

Install dependencies:

```bash
npm install
# or
yarn
```

Run the development server:

```bash
npm run dev
# or
yarn dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Project Structure

- `components/` - Reusable UI components
- `pages/` - Next.js pages and routing
- `styles/` - Global styles and SCSS variables
- `public/` - Static assets
- `utils/` - Utility functions
